# KING OF FOOLS — Artwork Approval Backlog

**Scope:** Beta project only. Do not publish artwork to production without explicit approval.

## Workflow
1. Generate a portrait animal/environment illustration, **without text, card borders, ranks, or suit symbols**.
2. Present the image to the user and record their feedback.
3. Only the user's explicit approval changes the status to **FINAL APPROVED**.
4. Preserve the final approved image file in the suit's deliverable set; do not substitute a later version.
5. Once **all 13 cards of one suit** are FINAL APPROVED, create a ZIP of those exact approved image files, plus this approval manifest (updated with filenames).
6. The site can be updated separately, after the user authorizes deployment. A GitHub code reference to a file is not an uploaded image.
